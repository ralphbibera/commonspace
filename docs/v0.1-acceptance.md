## Current release gates

- `pnpm check`: Biome, typecheck, and unit/integration tests; it does not build production artifacts.
- `pnpm verify:live`: fresh production build plus separate and installed serving modes, desktop Chromium mount, keyboard search/navigation, tag-first Project composition, and Light/Dark palettes through the appearance controls.
- `pnpm verify:service`: isolated real clone/install/build/plist/update/rollback under a temporary macOS home.
- `pnpm verify:acp`: real installed Codex and Hermes start plus exact native-session resume.
- `pnpm verify:acp:mcp`: real Codex and Hermes scoped context read, visible progress post, and exact final reply.

Before labeling a distribution build, repeat the opt-in real-harness and real-launchctl service checks on the clean supported release account. That is release-environment confirmation, not an unimplemented product capability.
